# Enterprise IT Service Desk & Ticketing Workflow Lab

## Overview
A hands-on IT Service Management (ITSM) lab built in **Jira Service Management** and **Confluence** to simulate Tier 1 Service Desk operations, SLA prioritization, incident troubleshooting, and Knowledge Base (KB) documentation.

## Key Workflows Demonstrated
* **Incident vs. Service Request Management:** Categorized incoming user tickets properly between system outages (Incidents) and standard access/onboarding requests (Service Requests).
* **SLA Prioritization:** Assigned urgency and priority levels (High, Medium, Low) to manage response and resolution timelines.
* **Structured Troubleshooting & Documentation:** Logged clear technical **Internal Notes** for IT team handoffs alongside plain-language **Customer Replies** for non-technical end users.
* **Knowledge Base (KB) Authoring:** Created self-service troubleshooting guides to reduce repeat tickets for common workplace issues.

## Simulated Tickets Handled
1. **[Incident - High]** Sales team unable to connect to Office Wi-Fi & VPN *(Resolved via DNS flush & IP lease renewal)*
2. **[Incident - Medium]** Windows workstation account lockout *(Resolved via Active Directory unlock & password reset verification)*
3. **[Incident - Low]** Network printer showing Offline status *(Resolved via Windows Print Spooler restart)*
4. **[Service Request - Low]** New hire Microsoft 365 & shared folder onboarding
